## Writing Standards
- Formal but friendly tone
- Plain language — avoid jargon
- Markdown formatting: use headings, tables, and lists

## File Naming
- Use lowercase-hyphen: `my-document.md`, `travel-memo-template.md`
- No `final`, `v2`, `copy` in file names — use commits for version history

## Commit Messages
- Short and descriptive: "Add event announcement template"
- Imperative mood: "Add" not "Added"
